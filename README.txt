배달 포인트 매니저 PWA
=========================

구성
- index.html: 앱 본체
- manifest.webmanifest: 설치 정보
- sw.js: 오프라인 캐시
- icons/: 앱 아이콘

중요: PWA 설치에는 HTTPS 주소가 필요합니다.
이 ZIP은 바로 설치되는 APK가 아니라, HTTPS 정적 호스팅에 올려 설치하는 PWA 패키지입니다.

가장 간단한 배포 방법(무료 GitHub Pages)
1. GitHub 계정에 새 Public repository를 만듭니다.
2. ZIP 압축을 풀고 파일과 icons 폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages > Deploy from a branch > main / (root) > Save를 선택합니다.
4. 잠시 후 표시되는 https://계정명.github.io/저장소명/ 주소를 갤럭시 S25 울트라의 Chrome에서 엽니다.
5. Chrome 오른쪽 위 ⋮ > 앱 설치 또는 홈 화면에 추가 > 설치를 누릅니다.
6. 앱을 한 번 실행한 뒤 오프라인 상태에서도 열리는지 확인합니다.

데이터 저장
- 입력 변경 시마다 브라우저 localStorage에 자동 저장됩니다.
- 데이터는 이 기기의 해당 브라우저/앱 저장공간에 남습니다.
- 브라우저 앱 데이터 삭제, 사이트 데이터 삭제, 앱 제거 시 데이터가 사라질 수 있습니다.
- 앱 안의 데이터 백업/복원에서 JSON 백업 파일을 주기적으로 내보내 별도 보관하세요.
- 이 앱은 서버로 데이터를 전송하지 않습니다.

운영 참고
- 같은 HTTPS 주소와 같은 브라우저 프로필로 실행해야 저장 데이터가 이어집니다.
- 새 버전 배포 시 sw.js의 CACHE 이름을 올려 캐시를 갱신할 수 있습니다.
